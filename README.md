# Rule 110 CA
The Rule 110 Cellular Automaton has its name because its update rule corresponds to the binary representation of the number 110 in binary form, 01101110.
The rule is a one-dimensional cellular automaton that is updated based on the two immediate neighbors of each cell.

Neighborhood | 111 | 110 | 101 | 100 | 011 | 010 | 001 | 000 |
-------------|-----|-----|-----|-----|-----|-----|-----|-----|
New Cell     |  0  |  1  |  1  |  0  |  1  |  1  |  1  |  0  |
